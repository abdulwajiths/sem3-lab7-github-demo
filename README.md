# sem3-lab7-github-demo

My AI Native Engineering Foundations lab work.

This repository demonstrates GitHub & Google Colab integration:

- Creating a repository on GitHub
- Connecting Google Colab to GitHub via "Save a copy in GitHub"
- Committing multiple versions of a Colab notebook

## Notebook

`sem3-lab7-github-demo.ipynb` contains seven versions of Python code:

1. `print("Connected and ready!")`
2. A name variable and a personalized greeting
3. An `int` variable with its data type
4. A `float` variable with its data type
5. An arithmetic calculation for marks (total and average)
6. A pass/fail check using a boolean condition
7. A loop over a list of subjects
